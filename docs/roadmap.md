# NegativeKit Roadmap

## v0.1 — First working prototype

Goal: prove the core workflow.

- Create SwiftUI macOS app
- Open TIFF, JPEG, PNG, and DNG
- Display imported image
- Apply basic negative inversion
- Add exposure slider
- Add contrast slider
- Export JPEG
- Export TIFF

---

## v0.2 — Usable negative conversion

Goal: make real scans look decent.

- Film base color picker
- Auto film border sampling
- Black point control
- White point control
- Temperature/tint controls
- Saturation control
- Reset adjustments
- Before/after toggle

---

## v0.3 — Better workflow

Goal: make the app pleasant to use.

- Drag-and-drop import
- Recent files
- Keyboard shortcuts
- Native toolbar
- Inspector/sidebar layout
- Better preview performance
- Save adjustment sidecar file

---

## v0.4 — Batch and presets

Goal: make it useful for full rolls.

- Batch import
- Batch export
- Copy/paste adjustments
- Preset system
- Film stock presets
- Export naming options

---

## v0.5 — Quality improvements

Goal: improve image science.

- Linear working pipeline
- Better color management
- Histogram display
- Curves adjustment
- LUT support
- Sharpening
- Grain controls

---

## v1.0 — Stable public release

Goal: make it safe to recommend.

- Signed macOS app
- Notarized release
- DMG installer
- GitHub Releases
- Documentation
- Example scans
- Homebrew Cask
- Basic contribution guide

---
